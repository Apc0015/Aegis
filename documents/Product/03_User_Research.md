# User Research Guidelines

## Research Methods

### Quantitative
- Surveys (minimum 100 responses for statistical significance)
- A/B testing
- Analytics analysis
- Usage pattern studies

### Qualitative
- User interviews (5-8 per study)
- Usability testing
- Focus groups
- Diary studies

## Research Process

### Planning
1. Define research questions
2. Choose methodology
3. Recruit participants
4. Prepare materials

### Execution
- Record sessions (with consent)
- Take detailed notes
- Include cross-functional observers
- Debrief after each session

### Analysis
- Tag and code responses
- Identify patterns
- Create user journey maps
- Develop personas

## Participant Recruitment

### Internal Database
- Existing customers who opted in
- Churned users
- Power users

### External Panels
- UserInterviews.com
- Respondent.io
- Craigslist (for general population)

### Incentives
- Customers: $75-150 gift cards
- General population: $100-200
- Enterprise: Custom incentives

## Research Repository
All research stored in Dovetail:
- Raw recordings
- Tagged insights
- Personas
- Journey maps
- Past recommendations
