# IT Help Desk Policies

## Service Level Agreements (SLAs)

### Response Times
| Priority | Definition | Response | Resolution Target |
|----------|------------|----------|-------------------|
| P1 - Critical | Business critical system down | 15 min | 4 hours |
| P2 - High | Significant impact | 1 hour | 8 hours |
| P3 - Normal | Standard requests | 4 hours | 24 hours |
| P4 - Low | Enhancement requests | 8 hours | 5 days |

### Priority Definitions

**P1 - Critical**
- Production system outage
- Security breach
- Data loss
- Company-wide email down
- VPN unavailable (all users)

**P2 - High**
- Single department impact
- Executive issue
- Important project blocker
- Application performance degraded

**P3 - Normal**
- Individual user issues
- Software installation
- Non-urgent requests
- Standard troubleshooting

**P4 - Low**
- Equipment refresh
- Feature requests
- Documentation updates
- Training requests

## Ticket Submission

### Preferred Methods
1. **Slack**: #it-helpdesk (fastest response)
2. **Email**: it@company.com
3. **Portal**: helpdesk.company.com (for tracking)

### Required Information
- Description of issue
- Error messages (screenshots)
- When issue started
- Steps already tried
- Impact scope

### Self-Service
- Password reset: helpdesk.company.com/reset
- Knowledge base: helpdesk.company.com/kb
- Equipment request: helpdesk.company.com/equipment

## Common Issues

### Password Reset
1. Go to helpdesk.company.com/reset
2. Enter email address
3. Follow email instructions
4. Contact IT if issues

### VPN Issues
1. Restart VPN client
2. Try alternate server
3. Check internet connection
4. Submit ticket with error message

### Software Installation
- Standard software: Request via Slack
- Non-standard: Manager approval required
- Cost >$100: Department budget approval

### Equipment Request
- New hires: HR submits request
- Existing employees: Manager approval
- Refresh cycle: 3 years for laptops
- Lost/damaged: Incident report required

## Remote Support

### Tools
- Slack screen sharing
- Zoom remote control
- TeamViewer (for external)
- SSH/RDP for servers

### Security
- User must initiate session
- Technician requests permission
- Session logged
- Remote access revoked after session

## Equipment Policies

### Standard Equipment

#### New Hires
- MacBook Pro (14") or Dell XPS 13
- External monitor (27")
- Keyboard and mouse
- Webcam and headset
- Laptop stand

#### Replacement
- Standard lifecycle: 3 years
- Exception: Damage or malfunction
- Approval: Manager + IT

### Personal Equipment
- BYOD not permitted for work
- No personal software on company devices
- Company data cannot be stored locally

### Lost or Stolen
1. Report immediately to IT
2. Remote wipe initiated
3. File police report (if theft)
4. Replacement device provisioned
5. Insurance claim if applicable

## Software Policies

### Approved Software
- IT maintains approved list
- Request additions via #it-helpdesk
- Security review required

### Prohibited Software
- Pirated software
- Personal cloud storage (Dropbox personal)
- Unauthorized VPNs
- Cryptocurrency miners
- P2P file sharing

### License Compliance
- IT tracks all licenses
- No sharing of accounts
- No installation on personal devices
- Audit compliance required

## After-Hours Support

### Emergency Only
- P1 issues only
- Call: (555) 0100
- Email: emergency@company.com

### Non-Emergency
- Submit ticket
- Response next business day
- Scheduled maintenance announced in advance

## User Responsibilities

### Security
- Lock computer when away
- Use strong passwords
- Report suspicious activity
- Complete security training

### Data
- Store files in approved locations (Google Drive)
- No sensitive data on local drives
- Backup important files
- Follow data classification

### Equipment Care
- Report damage immediately
- Clean screen with approved cloth
- Keep food/drink away
- Use carrying case for travel

### Acceptable Use
- Business purposes primarily
- Limited personal use OK
- No illegal activities
- No harassment or offensive content

## Escalation Process

### When to Escalate
- SLA not met
- Issue not resolved
- Recurring problem
- Dissatisfied with service

### How to Escalate
1. Ask to speak to IT Manager
2. Email: director-it@company.com
3. Include ticket number and history

### Continuous Improvement
- Weekly ticket review
- Trend analysis
- Knowledge base updates
