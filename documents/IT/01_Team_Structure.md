# IT Team Structure

## Mission
Deliver reliable, secure technology infrastructure and support that enables employee productivity and protects company data.

## Team Structure (4 members)

### Leadership
- Director of IT (1)

### IT Operations
- IT Manager (1)
- IT Specialist (1)
- IT Technician (1)

## Functional Areas

### Infrastructure
- Network management
- Server administration
- Cloud services (AWS)
- Backup and disaster recovery

### End User Support
- Help desk
- Equipment provisioning
- Software support
- Training

### Security
- Identity and access management
- Endpoint security
- Security monitoring
- Incident response

### Systems Administration
- Google Workspace / Office 365
- HRIS administration
- CRM administration
- Other SaaS platforms

## Key Responsibilities

### Service Desk
- First-line support for technical issues
- Ticket tracking and resolution
- SLA management
- Knowledge base maintenance

### Hardware Management
- Laptop procurement and provisioning
- Peripheral devices
- Mobile devices
- Asset inventory

### Software Administration
- User account provisioning/deprovisioning
- License management
- Access reviews
- Application configuration

### Security Operations
- Patch management
- Antivirus/EDR management
- Vulnerability scanning
- Security awareness

## Support Model

### Tiers
| Tier | Scope | Team |
|------|-------|------|
| Tier 1 | Password resets, basic troubleshooting | Help desk |
| Tier 2 | Application support, hardware issues | IT Specialist |
| Tier 3 | Complex issues, infrastructure | IT Manager/Director |

## Key Metrics
- First response time: <4 hours
- Resolution time: <24 hours (Tier 1-2)
- Customer satisfaction: >4.5/5
- System uptime: >99.9%
- Security incidents: 0 critical
